# Phase 6 — N3 hard-coded type masks

## Goal

Hard-code `mask_for_<type>(basis)` for every supported type in `BasisN3`
(including `TwistBivector`, which keeps its explicit 6-DOF named basis).

## Files

- Edit: `py/pytanga/geometry/create_n3.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **6.1 — enumerate + determine**
  - List N3-supported types (Point, Direction, Line, Plane, Sphere, Circle,
    PointPair, HPoint, HDirection, Space, Rotor, Translator, Motor,
    TwistBivector, Dilator, Inversion, ReflectionPlane, ReflectionLine,
    ReflectionPoint, GeneralRotor) and determine each full blade set.

- [x] **6.2 — hard-code**
  - Add `mask_for_<type>(basis) -> BladeMask` for each type with explicit ids;
    rename `basis_for_twist_bivector` → `mask_for_twist_bivector` (9 raw ids +
    6-DOF basis via `with_basis`).

- [x] **6.3 — tests**
  - Pin `mask_for(alg, Type).ids` and `.basis_names`; pin instance-subset.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
