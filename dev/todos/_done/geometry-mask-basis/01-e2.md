# Phase 1 — E2 named-basis sweep

## Goal

Ensure `mask_for(typ)` carries the correct named basis for every type supported
in `BasisE2` (2-D Euclidean; display basis = raw `e1, e2, e12` names).

## Files

- Edit: `py/pytanga/geometry/create_e2.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **1.1 — scan**
  - Enumerate E2-supported types (`Point`, `Direction`, `Space`, `Rotor`,
    `Line`-through-origin, `Plane`-through-origin) via `_template` + `create_e2`,
    and record `mask_for(typ).ids` / `.basis_names`.
  - Identify any type whose basis is missing or should be a type-specific
    (reduced/partial) basis instead of the auto display basis.

- [x] **1.2 — adapt**
  - Add `basis_for_<type>(basis)` to `create_e2.py` for any type needing an
    explicit basis; otherwise confirm the auto display basis is correct.

- [x] **1.3 — tests**
  - Add `assert_mask_basis` calls pinning `mask_for(typ).basis_names` for every
    E2-supported type.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
