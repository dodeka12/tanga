# Phase 2 — E3 named-basis sweep

## Goal

Ensure `mask_for(typ)` carries the correct named basis for every type supported
in `BasisE3` (3-D Euclidean; display basis = raw `e1, e2, e3, e12, …` names).

## Files

- Edit: `py/pytanga/geometry/create_e3.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **2.1 — scan**
  - Enumerate E3-supported types (`Point`, `Direction`, `Space`, `Rotor`,
    `Line`/`Plane`-through-origin, `ReflectionLine`/`ReflectionPlane`, …) and
    record `mask_for(typ).ids` / `.basis_names`.

- [x] **2.2 — adapt**
  - Add `basis_for_<type>(basis)` to `create_e3.py` for any type needing an
    explicit basis; otherwise confirm the auto display basis is correct.

- [x] **2.3 — tests**
  - Pin `mask_for(typ).basis_names` for every E3-supported type.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
