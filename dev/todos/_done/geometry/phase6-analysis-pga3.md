## 1. PGA3 Algebra Overview

| Property | Value |
|----------|-------|
| Basis class | `BasisPGA3` (extends `BasisN3`) |
| Dimension | 5 |
| Signature | 0b10000 |
| Blade count | 32 (2⁵) |
| Null vector | `einf = ep + em` only (no `eo`) |
| Geometric model | Projective, sub-algebra of N3 |

PGA3 uses the same C++ basis as N3 but only the subspace generated by
`{e1, e2, e3, einf}`. Entities that require `eo` (PointPair, Circle, Sphere)
are **not supported**. Operators that require `eo` (Inversion, Dilator,
GeneralDilator, GeneralRotor) are also **not supported**.

---

## 2. Entity Coverage

| Entity | Grade | Detection |
|--------|-------|-----------|
| Point | 1 | SP(point, einf) ≠ 0 (finite) |
| Direction | 1 | SP(point, einf) = 0 (ideal) |
| Line | 3 | 3 factor vectors = 2 points + einf |
| Plane | 4 | 4 factor vectors = 3 points + einf |
| Space | 5 | Pseudoscalar |

**Not supported:** PointPair, Circle, Sphere (require eo).

---

## 3. Operator Coverage

| Operator | # Factors | Detection |
|----------|-----------|-----------|
| Reflection | 1 | Euclidean-only factor (no einf/eo components) |
| Rotor | 2 | Both factors Euclidean |
| Translator | 2 | Factors involve einf |
| Motor | 4 | 2 Euclidean + 2 einf factors |

**Not supported:** Inversion, Dilator, GeneralDilator, GeneralRotor (require eo).

---

## 4. Point Detection

PGA3 point embedding differs from full N3. A PGA3 point is:
`x·e1 + y·e2 + z·e3 + einf`

where `einf = ep + em` (blade IDs 8 and 16). The point does **not** use `eo`.

**Extraction:**
1. Factorize the grade-1 blade → single factor vector.
2. Check: if factor has only `einf` components (no e1/e2/e3) → Direction.
3. Otherwise, extract e1, e2, e3 coefficients directly as (x, y, z).

The C++ `TryPointToVec3` approach for N3 uses `-SP(point, einf)` to get the eo weight — this is **not applicable** to PGA3 since PGA3 points don't have eo components. Instead, just read e1/e2/e3 directly.

# py/pytanga/geometry/analysis_pga3.py

"""PGA3-specific entity and operator analysis (single null vector).

PGA3 uses only the einf null vector and represents a projective model.
Entities requiring eo (PointPair, Circle, Sphere) are not available.
"""

import math

from pytanga.algebra._mv import MV
from pytanga.geometry.entities import Direction, Line, Plane, Point, Space


# --- Entity Detection ---

def analyze_entity(mv: MV) -> Point | Direction | Line | Plane | Space:
    """Analyze an MV in PGA3 as a geometric entity.

    PGA3 entities are pure-grade blades:
      - Grade 1: Point (finite) or Direction (ideal)
      - Grade 3: Line
      - Grade 4: Plane
      - Grade 5: Space
    """
    if mv.is_zero:
        raise ValueError("Zero MV is not a geometric entity")

    grades = _get_grades(mv)
    if len(grades) > 1:
        raise ValueError(f"Mixed-grade MV in PGA3: grades={grades}")

    max_grade = max(grades)

    if max_grade == 1:
        return _point_or_direction_pga3(mv)
    elif max_grade == 3:
        return _line_pga3(mv)
    elif max_grade == 4:
        return _plane_pga3(mv)
    elif max_grade == 5:
        return Space()
    else:
        raise ValueError(f"Unexpected grade {max_grade} in PGA3")


def _point_or_direction_pga3(mv: MV) -> Point | Direction:
    """Extract point from grade-1 PGA3 blade.

    PGA3 point: x·e1 + y·e2 + z·e3 + einf
    Direction:  x·e1 + y·e2 + z·e3 + 0·einf (pure Euclidean direction)
    """
    factor = mv.grade(1).blade_factorize()[0]
    x = float(factor[1])   # e1
    y = float(factor[2])   # e2
    z = float(factor[4])   # e3
    # Check einf components (ep=8, em=16)
    has_einf = abs(float(factor[8])) > 1e-15 or abs(float(factor[16])) > 1e-15
    if not has_einf:
        return Direction(x=x, y=y, z=z)
    return Point(x=x, y=y, z=z)

# --- Entity Construction ---

def make_point(alg, x: float, y: float, z: float) -> MV:
    """Create a PGA3 point: x·e1 + y·e2 + z·e3 + einf."""
    # einf = ep + em, ep=8, em=16
    return alg.multivector({
        1: x,    # e1
        2: y,    # e2
        4: z,    # e3
        8: 1.0,  # ep
        16: 1.0, # em
    })


def make_direction(alg, x: float, y: float, z: float) -> MV:
    """Create a PGA3 direction: x·e1 + y·e2 + z·e3."""
    return alg.multivector({1: x, 2: y, 4: z})


# --- Operator Detection ---

def analyze_operator(mv: MV):
    """Analyze an MV in PGA3 as a versor.

    Classification by factor count and einf content:
      - 1 factor, no einf  → Reflection
      - 2 factors, no einf → Rotor
      - 2 factors, with einf → Translator
      - 4 factors          → Motor
    """
    from pytanga.geometry.operators import Motor, Reflection, Rotor, Translator

    scale, factors = mv.blade_factorize_versor()
    n = len(factors)
    has_einf = [_factor_has_einf(f) for f in factors]

    if n == 1:
        return _reflection_from_factor(factors[0])
    elif n == 2:
        if any(has_einf):
            return _translator_from_factors(factors)
        else:
            return _rotor_from_factors(factors[0], factors[1])
    elif n == 4:
        return _motor_from_factors(factors)
    else:
        raise ValueError(f"Unexpected {n} factors for PGA3 versor")


# --- Helpers ---

def _get_grades(mv: MV) -> set[int]:
    return {b.bit_count() for b in mv.blade_ids()}


def _is_finite_point(factor: MV) -> bool:
    return abs(float(factor[8])) > 1e-15 or abs(float(factor[16])) > 1e-15


def _factor_has_einf(factor: MV) -> bool:
    return abs(float(factor[8])) > 1e-15 or abs(float(factor[16])) > 1e-15


def _factor_to_point(factor: MV) -> Point:
    return Point(x=float(factor[1]), y=float(factor[2]), z=float(factor[4]))
