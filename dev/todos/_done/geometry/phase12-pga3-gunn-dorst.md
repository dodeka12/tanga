# Phase 12: Refactor PGA3 as Gunn/Dorst 4D PGA via N3 Embedding

**Goal:** Re-implement `BasisPGA3`, `analysis_pga3.py`, and `create_pga3.py`
so that PGA3 behaves as the **Gunn/Dorst 4D projective geometric algebra**
(plane-based PGA), using the null-vector embedding ``einf = ep + em`` as the
single null vector ``e0`` (with ``e0² = 0``).  The ``eo`` vector is **not
used** for PGA3 point representation.

**Reference:**
- Gunn, *Geometric algebras for Euclidean geometry* (arXiv:1411.6502, 2016)
- Dorst, *A Guided Tour to the Plane‑Based Geometric Algebra PGA*
  (bivector.net/PGA4CS.html, 2020)
- `docs/py/basis/pga_null_embedding.md` — isomorphism proof

---

## 1. Core Principle: ``einf = ep + em`` as ``e0``

The isomorphism from `pga_null_embedding.md` establishes that the subspace
generated by ``{e1, e2, e3, einf}`` in G(5, 0b10000) is algebraically
isomorphic to the Gunn/Dorst PGA G(3, 0, 1) with ``e0² = 0``.

### 1.1 Pseudoscalar

The 4D pseudoscalar for the sub‑algebra is ``I_4d = e1 ∧ e2 ∧ e3 ∧ einf``.
Since ``einf`` is null, ``I_4d² = 0`` — it has **no proper inverse**.
However, the **pseudo‑inverse** ``blade_pseudo_inverse()`` provides a valid
dual operation:

```
I_4d_pinv = e1∧e2∧e3∧einf . blade_pseudo_inverse()
          = {e1234: 0.5, e1235: -0.5}
```

This pseudo‑inverse satisfies ``mv.ip(I_4d_pinv).ip(I_4d) == mv`` (round‑trip)
and maps grade‑1 → grade‑3 (and vice‑versa), which is exactly the Gunn/Dorst
4D dual relation.  The 5D ``sdual()`` is **not** used.

### 1.2 Approach

- **Creation:** Build blades in the convenient form (grade‑1 for planes and
  point‑IPNS vectors; grade‑3 for point trivectors) and apply
  ``ip(I_4d_pinv)`` once for OPNS ↔ IPNS conversion.
- **Analysis:** For OPNS mode, classify by grade and decompose via
  ``blade_factorize()``.  For IPNS mode, apply ``ip(I_4d_pinv)`` **once**
  (same as ``sdual()`` in E3/P3/N3), then run OPNS classification.
- **Convenience helper:** A module‑level ``_pga3_dual(mv)`` function that
  returns ``mv.ip(I_4d_pinv)``.  The pseudo‑inverse dual is **not**
  self‑inverse, but only a single application is needed in the pipeline.

## 2. Entity Grade Mapping (Gunn/Dorst)

| Entity | Grade | OPNS Representation |
|---|---|---|
| Plane | 1 | ``n + d·einf`` (4 basis blades) |
| Line | 2 | ``P1 ∧ P2`` — intersection of 2 planes (6 basis bivectors) |
| Point | 3 | ``P1 ∧ P2 ∧ P3`` — intersection of 3 planes (4 basis trivectors) |
| Direction | 3 | Point at infinity; in IPNS form ``x·e1 + y·e2 + z·e3`` (no einf) |
| Space | 5 | Pseudoscalar (the 5D pseudoscalar of the ambient algebra) |

### 2.1 Plane (Grade 1)

A plane with unit normal ``(nx, ny, nz)`` and signed distance ``d`` from
the origin:

```
P = nx·e1 + ny·e2 + nz·e3 + d·einf
  = nx·e1 + ny·e2 + nz·e3 + d·(ep + em)
```

**Blade IDs:** ``{e1(1), e2(2), e3(4), ep(8), em(16)}``.
The coefficients on ``ep`` and ``em`` are equal (both ``d``).

**Extraction:** Read ``e1, e2, e3`` for the normal, ``ep`` for the offset.

### 2.2 Line (Grade 2)

A line is the intersection of two planes ``L = P1 ∧ P2``.

**Basis bivectors:** ``{e23, e31, e12, e1∧einf, e2∧einf, e3∧einf}``
(6 basis elements, each split across ep/em = 12 blade IDs).

**Extraction:** Factorize the grade‑2 blade → 2 plane vectors → decompose
each plane → cross product of normals gives line direction; solving the
two plane equations gives a point on the line.

### 2.3 Point (Grade 3)

A point is the intersection of three planes ``P = P1 ∧ P2 ∧ P3``.

**Basis trivectors:** ``{e23∧einf, e31∧einf, e12∧einf, e123}``
(4 basis elements, each split across ep/em = 8 blade IDs).

**Extraction:** Factorize the grade‑3 blade → 3 plane vectors → solve the
3×3 linear system for the intersection point in Euclidean coordinates.

**IPNS form (dual):** For a finite point, the dual (grade‑1 IPNS) is:

```
P* = x·e1 + y·e2 + z·e3 + einf
```

with NO ``eo`` component.  This is constructed directly as a grade‑1
multivector.  For an ideal point (direction), the dual is:

```
D* = x·e1 + y·e2 + z·e3
```

(no einf component).  The distinction: ``coeff(ep) == coeff(em) ≠ 0``
means finite; ``coeff(ep) == coeff(em) == 0`` means ideal.

## 3. Implementation Changes

### 3.1 `py/pytanga/basis/pga3.py`

```python
class BasisPGA3(BasisN3):
    """Gunn/Dorst 4D PGA via N3 null-vector embedding.

    Implements the plane‑based projective geometric algebra described in:

    - Charles Gunn, *Geometric algebras for Euclidean geometry*,
      arXiv:1411.6502 (2016).

    - Leo Dorst, *A Guided Tour to the Plane‑Based Geometric Algebra PGA*,
      bivector.net/PGA4CS.html (2020).

    The Gunn/Dorst model uses a single null basis vector e0 with e0² = 0.
    Since TANGA's Clifford algebra only supports metric signatures with
    squares ±1, the null vector is modelled via the embedding

        e0 → einfi = ep + em,   ep²=+1, em²=-1,

    as documented in ``docs/py/basis/pga_null_embedding.md``.  The pair
    (ep, em) generates the 5‑dimensional algebra G(5, 0b10000); the
    subspace {e1, e2, e3, e0} is algebraically isomorphic to the
    Gunn/Dorst 4D PGA.

    The eo vector (0.5·em - 0.5·ep) is NOT used for point representation.
    """

    def point(self, x: float, y: float, z: float) -> MV:
        """Point in IPNS/dual form: x·e1 + y·e2 + z·e3 + einf."""
        return self.multivector({1: x, 2: y, 4: z, _EP: 1.0, _EM: 1.0})

    def direction(self, x: float, y: float, z: float) -> MV:
        """Direction (ideal point) in IPNS/dual form: x·e1 + y·e2 + z·e3."""
        return self.multivector({1: x, 2: y, 4: z})

    def plane(self, nx: float, ny: float, nz: float, d: float = 0.0) -> MV:
        """Plane (grade-1): nx·e1 + ny·e2 + nz·e3 + d·einf."""
        return self.multivector({1: nx, 2: ny, 4: nz, _EP: d, _EM: d})
```

```
"""PGA3-specific entity and operator analysis.

Implements the Gunn/Dorst plane‑based PGA model (G(3, 0, 1)) within the
5D N3 algebra via the null‑vector embedding einfi = ep + em.  This
embedding is necessary because TANGA does not support zero‑squaring basis
vectors natively; see ``docs/py/basis/pga_null_embedding.md`` for the
mathematical isomorphism.

Entity grades follow the Gunn/Dorst convention:
  - Plane  = grade‑1 vector   (Gunn §4.2, Dorst §3.1)
  - Line   = grade‑2 bivector (intersection of two planes)
  - Point  = grade‑3 trivector (intersection of three planes)
  - Direction = grade‑3 trivector, dual has no einfi component

References:
  Gunn, *Geometric algebras for Euclidean geometry* (arXiv:1411.6502, 2016)
  Dorst, *A Guided Tour to the Plane‑Based Geometric Algebra PGA* (2020)
  ``docs/py/basis/pga_null_embedding.md``
"""
```

**OPNS mode:**
- Grade 1 → Plane: extract normal + offset from coefficients.
- Grade 2 → Line: factorize into 2 plane vectors → extract line parameters.
- Grade 3 → Point: factorize into 3 plane vectors → solve for intersection.
- Grade 5 → Space.

**IPNS mode:** Apply ``_pga3_dual(mv)`` (pseudo‑inverse dual), then run OPNS
analysis.  This is the same pattern as E3/P3/N3 IPNS via ``sdual()``.

**Operator analysis:** unchanged.

    if not opns:

    einf = {8: 1.0, 16: 1.0}
