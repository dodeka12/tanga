# Phase 4 — Docs, example, changelog

## Goal

Document `ToolbarView` and the shared layout enums, rework the toolbar example
into a four-pane vertical `SplitView` that showcases each `justify` alignment,
and record the change in the branch changelog.

## Files

- Edit: `docs/py/viz/visualizer/split-views.md`
- Edit: `py/examples/viz/scenes/toolbar.py`
- New: `docs/changelog/YYYY-MM-DD_feat-view-architecture.md` (append, do not
  create a new file)
- Edit: generated `docs/py/examples/**` (via the example-docs generator)

## Steps

- [x] **4.1 — Layout reference (`split-views.md`)**
  - Add a `### ToolbarView` subsection under the "Horizontal stacks & toolbars"
    area, documenting `margin` / `border` / `gap` / `align` / `justify` and the
    four alignment mappings (`START`/`END`/`CENTER`/`SPACE_EVENLY`).
  - In the "Spacing, alignment, and flexible children" section, note that
    `direction` / `align` / `justify` now accept `EStackDirection` /
    `EStackAlign` / `EStackJustify` (plain strings still accepted).

- [x] **4.2 — Example (`toolbar.py`)**
  - Rework the example into a `SplitView(orientation="vertical", sizes=[...4 equal...])`
    with **four panes**, each pane a `ToolbarView` holding the **same content
    elements** (e.g. three `ButtonView`s) but with a different `justify`:
    `EStackJustify.START` (left), `END` (right), `CENTER` (block center),
    `SPACE_EVENLY` (equally spaced).
  - Make each row self-describing: lead each toolbar with a button labelled
    with its alignment (or add a per-pane comment).  Demonstrate `margin=`,
    `border=`, and `gap=` on at least one pane (defaults elsewhere).
  - Drop the now-unused scene/`SceneView`/handlers; update the module docstring
    and `Keywords:` header to match (e.g. `scenes, split view, toolbar,
    alignment, vertical, layout`).
  - Run `uv run python tools/generate-example-docs.py` and
    `uv run python tools/generate-example-docs.py --check`; revert any unrelated
    generated-doc drift (as in prior example changes).

- [x] **4.3 — Changelog**
  - Run `uv run python tools/last-release.py` for the since-relative title.
  - Append a `## New Features` bullet to the branch changelog
    (`docs/changelog/*_feat-view-architecture.md`): `ToolbarView` +
    `EStackDirection`/`EStackAlign`/`EStackJustify`.
