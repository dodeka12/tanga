# Phase 1 — E2 hard-coded type masks

## Goal

Replace instance-derived masks with hard-coded `mask_for_<type>(basis)` for every
supported type in `BasisE2`.

## Files

- Edit: `py/pytanga/geometry/create_e2.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **1.1 — enumerate + determine**
  - List E2-supported types (`Point`, `Direction`, `Space`, `Rotor`,
    `ReflectionLine`) and read each `create_<type>` to determine its full blade
    set (explicit ids).

- [x] **1.2 — hard-code**
  - Add `mask_for_<type>(basis) -> BladeMask` for each type with explicit ids.

- [x] **1.3 — tests**
  - Pin `mask_for(alg, Type).ids` and `.basis_names` for every type; pin
    `mask_for(alg, instance)` is a subset of the type mask.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
