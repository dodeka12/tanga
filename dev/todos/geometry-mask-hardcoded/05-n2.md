# Phase 5 — N2 hard-coded type masks

## Goal

Hard-code `mask_for_<type>(basis)` for every supported type in `BasisN2`, fixing
the partial masks that the old `_template` produced (Sphere, Circle, Inversion).

## Files

- Edit: `py/pytanga/geometry/create_n2.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **5.1 — enumerate + determine**
  - List N2-supported types (Point, Direction, Line, Sphere, Circle, PointPair,
    HPoint, HDirection, Space, Rotor, Translator, Motor, Dilator, Inversion,
    ReflectionLine, ReflectionPoint, GeneralRotor) and determine each full blade
    set from the create function (correct the old partial masks: Sphere/Circle →
    full grade-3, Inversion → full grade-1).

- [x] **5.2 — hard-code**
  - Add `mask_for_<type>(basis) -> BladeMask` for each type with explicit ids.

- [x] **5.3 — tests**
  - Pin `mask_for(alg, Type).ids` and `.basis_names`; assert the previously
    partial masks are now full; pin instance-subset.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
