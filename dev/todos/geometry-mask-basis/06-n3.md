# Phase 6 — N3 named-basis sweep

## Goal

Ensure `mask_for(typ)` carries the correct named basis for every type supported
in `BasisN3` (3-D conformal; display basis `e1, e2, e3, einf, eo`).  `TwistBivector`
already has its 6-DOF basis from `expression-basis-tensor` Phase 4 — confirm it
and cover the remaining types.

## Files

- Edit: `py/pytanga/geometry/create_n3.py`
- Edit: `py/tests/geometry/test_geometry_mask.py`

## Steps

- [x] **6.1 — scan**
  - Enumerate N3-supported types (`Point`, `Direction`, `HPoint`, `HDirection`,
    `Line`, `Plane`, `Sphere`, `Circle`, `PointPair`, `Space`, `Rotor`,
    `Translator`, `Motor`, `TwistBivector`, `Dilator`, `Inversion`,
    `Reflection*`, `GeneralRotor`, …) and record `mask_for(typ).ids` /
    `.basis_names`.
  - Confirm `Point` → `['e1','e2','e3','einf','eo']` (auto display basis) and
    `TwistBivector` → 6 physical DOF (already implemented).

- [x] **6.2 — adapt**
  - Add `basis_for_<type>(basis)` to `create_n3.py` for any type needing an
    explicit basis; keep `basis_for_twist_bivector` unchanged.

- [x] **6.3 — tests**
  - Pin `mask_for(typ).basis_names` for every N3-supported type.

## Validation

`uv run pytest py/tests/geometry/test_geometry_mask.py -q`
