# Phase 1 — Consolidate the JS toolchain under `js/dev/`

> **Architecture note — check the developer docs.** Before implementing, check
> `docs/dev/` (especially `docs/dev/architecture/`) for the subsystem(s) this
> work touches, so the new code aligns with the documented architecture.  If
> this work introduces or changes architecture, update the developer docs.

## Goal

Move the JS toolchain manifest out of `dev/` and into `js/dev/`, and make sure
`node_modules/` can never be committed. `js/tanga-viewer.js` and
`js/tanga-viewer.manifest.json` stay exactly where they are.

## Files

- New (moved): `js/dev/package.json` ← `dev/package.json`
- New (moved): `js/dev/package-lock.json` ← `dev/package-lock.json`
- Edit: `.gitignore` (add `node_modules/`)
- Delete: `dev/package.json`, `dev/package-lock.json`, `dev/.gitignore`

## Steps

- [x] **1.1 — Move the manifest into `js/dev/`**
  - `git mv dev/package.json js/dev/package.json`
  - `git mv dev/package-lock.json js/dev/package-lock.json`
  - `js/tanga-viewer.js` + `js/tanga-viewer.manifest.json` are **not** touched.

- [x] **1.2 — Update `js/dev/package.json`**
  - `"name": "tanga-js-dev"` (or similar), keep `esbuild` + `playwright`
    devDependencies.
  - Replace the `scripts` block with:
    ```json
    "scripts": {
      "test": "node --test tests/*.test.mjs",
      "check": "node tests/check-syntax.mjs",
      "smoke": "node tests/reconcile-smoke.mjs"
    }
    ```
  - Note in a comment that `package-lock.json` is regenerated by `npm install`.

- [x] **1.3 — Gitignore `node_modules/`**
  - Add `node_modules/` to the root `.gitignore` (covers `js/dev/node_modules`
    and any future one).
  - Delete `dev/.gitignore` (its `node_modules/`/`dist/`/`.env` rules are
    superseded; `js/dev/` will get its own ignore if needed).

- [x] **1.4 — Verify the published artifact is untouched**
  - Confirm `git status` shows only the move + `.gitignore` change (no
    modification to `js/tanga-viewer.js` / manifest).
  - Run the bundle drift check.

## Validation

```
git status --short
uv run python tools/build-viewer-js.py --check
```

## Notes

- `js/tanga-viewer.js` is served by jsDelivr for `delivery="cdn"` and written by
  `tools/build-viewer-js.py`; it must remain at `js/` top level.
- `npm install` (run later in the node-equipped clone, inside `js/dev/`) creates
  `js/dev/node_modules/` and refreshes `package-lock.json`.
