# Pull Request

Open a pull request for a finished feature/fix branch — one branch, one squashed
commit, one changelog — and only once the full validation gate is green.

## Read the full workflow first

Read and follow `dev/workflows/pull-request.md` — it is the authoritative
procedure (validation gate and its expected skips, backup branch, squash,
changelog rename, PR body, push).  The changelog itself follows
`dev/workflows/changelog.md`.
