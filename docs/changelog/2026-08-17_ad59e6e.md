# Changes since version 0.9.2

## New Features
- **`content` aspect for in-place entity updates** — replacing an entity's
  geometry (same kind) now emits a `content` patch that mutates the inner
  three.js mesh in place, preserving the node's transform, parent, style, and
  id mapping instead of a full destroy-and-rebuild. A kind change still emits
  `full`.

## Refactor
- **Single frontend registry (`sceneObjects`)** — removed the legacy
  `entityMeshes`/`entityData`/`labelObjects` maps and the old flat-entity path
  (`updateEntity`, `inPlaceUpdate`, `upsertLabel`, and the `msg.entities`/
  `msg.labels` branches), so all updates flow through the aspect-scoped
  `object_update` handler against one `{obj, mesh, data, layer, el?}` registry.
