# Changes since version 0.9.2

## Refactor
- **Unified live/export render pipeline** — the live viewer and the
  static/animated HTML export now build the three.js scene through one shared
  `templates/scene-builder.js` module (`buildSceneObject` / `buildOverlay` /
  `removeObject`), so node-transform wrapping, `parent_id` parenting, and
  label `attach_to` handling are implemented once instead of being duplicated
  between `viewer.js` and the export bootstrap. Exporters now consume
  `Scene.full_state()` directly, and the legacy `_serialize_labels()` /
  `parentId` label path is removed.
