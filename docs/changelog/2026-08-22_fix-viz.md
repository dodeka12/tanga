# Changes since version 0.13.0

## New Features
- **`show()` works in Jupyter notebooks** — `Visualizer.show()` and
  `VizSceneHandle.show()` now accept a `jupyter` option (`None` auto-detects,
  `True` forces the notebook display, `False` forces a browser tab) and, in
  Jupyter, delegate to `display()` so `show()` is the single entry point for
  showing a scene.

## Bug Fixes
- **`display()` hints when the server is not running in Jupyter** —
  `Visualizer.display()` and `VizSceneHandle.display()` now print a hint to
  call `start_server()` (and skip the iframe) when invoked in a Jupyter
  notebook before the server is running, instead of rendering an empty frame.
