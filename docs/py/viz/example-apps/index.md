# Example Apps

Full, runnable applications under `py/examples/apps/` that combine the viewer,
the interactive entities, and the UI/control system into complete tools.  Each
one is a concrete `VisualizerApp` you can run as-is or copy and adapt.

| App | What it does |
|-----|--------------|
| [Image Labeling](image-labeling-app.md) | Draw, select, and delete labelme shapes on an image; load/save labelme JSON |
